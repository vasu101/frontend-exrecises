# Semantic HTML CV

<img width="685" height="1624" alt="simple-portfolio" src="https://github.com/user-attachments/assets/80601761-7f67-4a15-9b13-0bb2e9b21c66" />

A single-page CV built with semantic HTML to demonstrate proper web structure and SEO practices.

## Aim

This project showcases my understanding of:
- **Semantic HTML5** - Using the right tags for the right content
- **SEO best practices** - Meta tags for better search engine visibility
- **Social media optimization** - Open Graph tags for sharing
- **Web accessibility** - ARIA labels and proper document structure
- **Clean code** - Readable, maintainable HTML

## Features

- Semantic HTML tags (`header`, `main`, `section`, `article`, `footer`, `nav`, `time`, `address`)
- SEO meta tags (description, keywords, author)
- Open Graph tags for social media sharing
- Favicon implementation
- Accessible markup with ARIA attributes
- Mobile-responsive design
- Properly structured content hierarchy

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
.
├── index.html          # Main CV page
├── styles.css          # style for CV   
├── favicon.png         # Site favicon
└── README.md          # This file
```

## How to View

Simply open `index.html` in any modern web browser.

```bash
# Or use a local server
python -m http.server 8000
# Then visit: http://localhost:8000
```

## Key Learnings

- Importance of semantic markup over generic `<div>` tags
- How proper meta tags improve SEO and social sharing
- Using `<time>` elements with `datetime` attributes for dates
- Structuring a professional CV with appropriate HTML5 elements
- Making content accessible with ARIA labels
