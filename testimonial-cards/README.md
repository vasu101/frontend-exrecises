# Testimonial Cards

A collection of four different testimonial card designs built with HTML and CSS.

## Project Overview

This project contains four types of testimonial cards:
- Speech bubble card with dark background
- Simple bordered card
- Split card with photo and dark content area
- Carousel card with multiple profile images

## Technologies Used

- HTML5
- CSS3

## Key Features

- Responsive design for mobile, tablet, and desktop
- CSS Grid layout for card arrangement
- BEM naming convention for CSS classes
- CSS custom properties for easy theming
- All sizing done with rem units for better accessibility

## What I Learned

- Creating speech bubble effects with CSS pseudo-elements
- Using CSS Grid to span elements across multiple columns
- Implementing BEM naming methodology
- Working with rem units instead of pixels
- Building responsive layouts with media queries
- Organizing CSS with variables and sections
