# Age Calculator

A simple web-based age calculator that calculates your exact age in years, months, and days.
<img width="744" height="805" alt="age-calculator" src="https://github.com/user-attachments/assets/94d72c02-bc63-4be9-a00b-46e2efbbdcfc" />

## Features

- Mobile-style scrollable date picker interface
- Modern and responsive UI design
- Input validation for valid dates
- Uses Luxon library for accurate date calculations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Luxon (Date/Time library)
