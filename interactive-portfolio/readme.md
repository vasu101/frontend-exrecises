# 💼 Personal Portfolio - Nishant Singh Shekhawat

A modern, responsive portfolio website built with semantic HTML5 and pure CSS3. This project showcases professional experience, projects, education, and peer reviews in a clean, accessible design.

## ✨ Features

- **Fully Responsive** - Seamlessly adapts from desktop to mobile devices
- **Semantic HTML5** - Proper use of semantic elements for better SEO and accessibility
- **Modern CSS3** - CSS Grid, Flexbox, custom properties, and smooth animations
- **Zero Dependencies** - No frameworks or libraries required
- **Accessible** - ARIA labels and semantic structure for screen readers
- **Performance Optimized** - Single-file architecture with fast load times
- **Professional Design** - Clean, modern interface with hover effects and transitions

## 🚀 Quick Start

1. Clone or download the project
2. Open `index.html` in your web browser
3. That's it! No build process or dependencies needed

```bash
# Option 1: Open directly
open index.html

# Option 2: Use a local server (recommended)
npx serve .
# or
python -m http.server 8000
```

## 🎨 Design Highlights

### CSS Architecture
- **CSS Custom Properties** for easy theming
- **Fluid Typography** using `clamp()` for responsive text
- **CSS Grid** with `auto-fit` for intelligent layout adaptation
- **Mobile-First** approach with progressive enhancement

### Responsive Breakpoints
- **Desktop**: > 768px (3-column grid layout)
- **Tablet**: ≤ 768px (2-column or stacked layout)
- **Mobile**: ≤ 480px (single column, optimized navigation)

### Color Scheme
- Primary: `#000` (Black)
- Secondary: `#666` (Gray)
- Accent: `#0066cc` (Blue for links)
- Background: `#fff` (White)

## 🔧 Customization

### Changing Colors
Edit the CSS custom properties in the `:root` selector:

```css
:root {
    --primary-color: #000;
    --secondary-color: #666;
    --border-color: #ddd;
    --hover-color: #888;
}
```

### Adjusting Spacing
Modify the spacing variables:

```css
:root {
    --spacing-sm: 1rem;
    --spacing-md: 1.5rem;
    --spacing-lg: 2rem;
}
```

### Updating Content
Simply edit the HTML content within the respective sections:
- Navigation links
- Hero section text
- Projects list
- Experience details
- Education information
- Reviews
